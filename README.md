# Psych Quest: REBT & Reality Therapy

A playable, gamified study reviewer for two counseling theories:
Rational Emotive Behavior Therapy (Albert Ellis) and Reality Therapy (William Glasser, Robert Wubbolding).

**Play it:** https://vinzy0.github.io/psych-quest-rebt-reality/

- 6 units, 16 lessons, 28 learn cards, 94 questions, 6 match rounds
- Hearts, XP, streaks, a guidebook per unit, Practice Mistakes, and a Final Boss with every review question
- Single HTML file, no build step. Progress is saved in your browser only.
